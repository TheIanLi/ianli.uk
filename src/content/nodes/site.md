这个站从我发出第一句话到上线，用了 16 个小时，中间我还睡了一觉。代码全是 Claude Code 写的，我一行没写。我干的事是提需求、看结果、说不行、验收。

域名是早就有的。当初买它只是因为要建 VPS，经常买鸡，所以得有一个。之后就一直没用，感觉有点浪费，就开始想拿它干点啥。想到的是写博客，写点文章什么的。一开始还想过做游戏，但也不知道做啥游戏，就先这样了。

## 9 日晚上

10 月 9 日晚上 11 点 14 分开的工。我带了两样东西：一份需求，一个之前让 Claude 做的单文件原型。原型是个 3D 星图，每个点是一篇笔记，做得很草率，但方向我是满意的。

需求里我原本写的是不用 React，首页的 JS 压到 300KB 以内。同一条消息里我又贴了抖音上刷到的五个"提升网页质感"的网站，让它看看哪些能用。它查完说其中两个组件库只支持 React，和我自己写的约束冲突。十几分钟后我把约束改了：允许 React，体积放宽到 600KB 左右，真正卡死的指标换成帧率。

它本来想一个一个问我问题，我让它一次问完。它列了 15 个，我统一答了。

这两天有些时候我人不在电脑前。Claude Code 有个 Remote Control，电脑上开着，我在手机上就能接着给它发消息。但它做出来的预览页是电脑本机的地址，手机上打不开，所以我再用 UU 远程连回电脑，在电脑的浏览器里看效果。

12 点前，骨架和第一版 3D 星图就出来了。我在需求里给自己定过一条规矩：特效每做完一项先停下，我在浏览器里看过再做下一项。结果 12 点半我困了，跟它说："不用等我确认了，直接 12345 都做了就行了。我正准备休息，你自己看着办吧。明天起床我会验收的。"它用半个小时把五项做完，然后等了我一晚上。

## 10 日上午

早上 8 点半验收。中间的太阳太亮，连线也亮，跟光污染似的。周围的节点只是几个发光的多边形，背景像一张贴图。我问它：这不像是你的审美啊，这就是最终版？

它说这不是最终版，然后自己列了原因。节点的造型没动，只是给原型里的线框立方体、八面体加了辉光。亮的地方没做压缩，直接糊成一片白。还有一条：它是在一个没有显卡的环境里一张张截图自查的，只看了功能有没有跑通。

它重做了一轮。太阳变成带日冕的恒星，节点变成行星和小星系，连线压暗。我中午看完更不满意，原话是"这个设计太 low 了""就像一几年大家用的风格"。我甚至在想要不要重构。

整个过程最烦的就是设计，因为很难想出让自己满意的设计。我想要的是干净、有高级感、有质感的东西，但我不知道该怎么说。它描述方案，我也想象不出来，得看到 demo 才知道。

它的说法是自己在堆效果：辉光、光环、线框笼、星芒、胶片颗粒，每样都常见，叠到一起就是那个年代的味道。它给了几个做得好的 3D 网站让我看。lusion.co 简洁大方，但我觉得有点炫技。igloo.inc 简单、互动性强，但我点不开。然后它做了三个不同风格的小样让我挑。

三个我都看了，给我的感觉是还不如它重做的那一版。那一版的思路是对的，交互也有意思，我烦的其实只有两样：背景不能互动，节点画得不好看。最后就在那一版上改这两样。节点外面套的那层线框全部去掉，背景做成鼠标能拨动星星、点一下会荡开波纹。三个小样删了。

所以这个上午的路线是：嫌它 low，看了三个新方向，又回到被我嫌 low 的那一版。

## 10 日下午

下午是一堆小毛病。

鼠标放到节点上，节点会自己跑，我得追着它。原因有三个叠在一起，主要的一个是镜头会跟着鼠标倾斜，我往节点那边移，画面就转，节点跟着挪走。

然后是卡。我当时就是通过 UU 远程在看，第一反应是 AI 写了一堆没用的代码，AI 好像都有这毛病。它说没执行的代码不会让画面变卡，远程桌面要把一直在动的 3D 画面实时压成视频传过来，本身就卡。它加了个 `?fps`，网址后面带上就能看帧率。我测了，基本 60 以上。我就说 4060 怎么可能带不起来一个网页。

点节点那一下是真的会卡。它查出来最大的一项是卡片弹出时量了一下自己的宽高，这一量逼着浏览器把整页重新排一遍，而页面上 19 个标签每一帧都在动。一行代码放错了时机。改完，点击那一刻主线程忙的时间从 530 毫秒降到 315 毫秒，这是它在自己那边量的数。

这一天有不少时间花在假问题上。Claude Code 跑在 WSL 里，它自己开的浏览器没有显卡，一秒只能画一两帧。它看到的卡和我看到的卡不是一回事，鼠标的手感它根本试不了，只能截图。下次做这种东西我直接在 Windows 里跑它。[细节在这篇](/n/fps-real-device/)。

名字我也不满意，字体不好看，就几个字在那显示着。它做了个对比页，放了四种方案，我挑了两个合起来用：开场时星尘拼出名字，然后飞到左上角变成正常的字。做完我刷新，没看到。画面从一个小光点卡了一下，星系直接弹出来了。原因是开场动画按现实时间走，页面刚打开那几秒浏览器在忙别的，画面卡着，开场却照样在"播"，等画面动起来它已经播完了。改成按帧走，画面卡住时开场也停。[细节在这篇](/n/intro-clock/)。

到这儿我有点怕陷入无尽的修改、无尽的修 bug 里。我让它先别急着做，去查查别人做这种网页都踩过哪些坑。它派了个后台任务，说要 15 到 30 分钟。我嫌多："不用查这么多，大概查一下比较常用的就行了……没必要这么较真……我额度也有限。"一分钟后我又改口了：算了，继续吧，别出 bug 就行。

它查了 25 分钟。有两条是真问题。一条是它之前告诉我帧率不够会自动一直降画质，其实降不到底。另一条是手机显存紧张时画面会直接黑掉。它还顺带翻出一个从第一版特效起就有的 bug：一张用来垫背景的大光晕图盖在了恒星和行星上面，把它们压暗了九成。它自己之前也觉得行星偏暗，原因之一在这。

## 上线之后

下午 3 点多准备上线。推代码前发现一件事：早期的提交记录里写着我两个不想公开的子域名。文件里已经删了，但历史里还在，仓库又是公开的。最后推上去的是一个全新的"初始提交"，之前的提交留在本地一个不推送的分支上。所以 GitHub 上看不到前面这些过程。[细节在这篇](/n/git-history-private-names/)。

Cloudflare 后台是我用手机点的，当时人不在电脑前。把仓库连到已有的 Worker 上，它再推一个提交触发构建，不到一分钟站就更新了。15 点 28 分，上线。

5 分钟后我用手机打开："一直在抖动、抽搐，是什么鬼？"整个星系在抖，每个节点在疯转，电脑上没有。它先猜是陀螺仪把手抖放大了，让我把手机平放在桌上试试。我放了，照样抖。真正的原因只有一行：

```ts
advance(t);          // 改之前
advance(t / 1000);   // 改之后
```

手机上有一段把帧率封顶到 60 的代码，把时间按毫秒传给了 3D 库，库要的是秒。手机上所有动画都在以 1000 倍速播放。电脑不走这段代码。[细节在这篇](/n/r3f-advance-seconds/)。

接着是竖屏太挤，星系被拉成一个竖着的菱形。再接着，纯国内网络打不开。3D 那部分有 400KB 左右，15 秒没下完，页面就自动跳成了 2D 列表。我的反应是："靠，现在把这个放在我的 VPS 上还来得及吗？"想单独买一台日本的小机来放网站。

其实没被墙，只是单纯的慢。先让它把加载改了：显示真实的下载进度，不再 15 秒强制跳走，下载过的文件让浏览器长期缓存。晚上我发现只有第一次打开卡，后面都不卡，就又不想买了。

傍晚朋友用苹果手机打开，说有点糊。我自己的手机上一直是清楚的。原因是它靠 CPU 核数判断手机档次，核数少就当低端机，而 iPhone 报给网页的核数不是真的，比实际的少。于是所有 iPhone 都被分到最低档：三倍屏只按一倍画，辉光也关了。这个它事先不知道，我更不知道，是朋友的手机试出来的。我干脆让它所有设备都从最高档开始，跑不动再自己往下降。[细节在这篇](/n/ios-hardware-concurrency/)。

晚上好几个朋友看了都说厉害，我又想起给他们也各分一个子域名的事，那是另一篇了。

到现在还没搞定的：星系的排法我想换成真正的旋臂星系，预览做了一半，旋臂不明显，还在本地没上线。文章页和 404 页没打磨。特效我也还没有特别满意，可能我要求太高了。还有这个站里的 19 篇笔记，除了这篇，正文都还写着"待补充"。
